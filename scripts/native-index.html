Linux

Requires native Linux, Bash and Python 3.10+. The standalone script contains its Python backend; no separate source folder is needed.

curl -fL https://motebus.github.io/download/agpc.sh -o agpc.sh
bash ./agpc.sh info --json

Windows

Requires native PowerShell 7.4+ matching the host CPU. Download the executable for your CPU. The preview EXEs are unsigned.

curl.exe -fL https://motebus.github.io/download/agpc.exe -o agpc.exe
.\agpc.exe info -Json

On ARM64, download agpc-arm64.exe instead and run .\agpc-arm64.exe info -Json.

Preview scope

Native installation is not implemented. The install command returns unavailable (exit 2), verified on Linux and Windows x86-64.

Run without elevation. Commands provide diagnostics, Codex App-Server health checks and read-only MCP discovery. These files do not install the full AGPC stack, configure SSH/RDP or start services. Windows host acceptance and operational RDP-over-Mote integration remain pending. macOS remains specification-only.
