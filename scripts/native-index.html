Linux

Installation requires native Ubuntu 24.04/26.04 x86-64, systemd, Bash and Python 3.10+. The standalone script embeds its backend. ARM64 installation is deferred; explicit diagnostics remain available.

curl -fL https://motebus.github.io/download/agpc.sh -o agpc.sh
bash ./agpc.sh install --dry-run
sudo bash ./agpc.sh install
agpc status

The core includes uChat. Install optional MDESK, MLINK and SS-WebOS after the core:

curl -fsSL https://motebus.github.io/download/agpc-apps.sh | sudo bash

Windows

Requires native PowerShell 7.4+ matching the host CPU. Download the executable for your CPU. The preview EXEs are unsigned.

curl.exe -fL https://motebus.github.io/download/agpc.exe -o agpc.exe
.\agpc.exe info -Json

On ARM64, download agpc-arm64.exe instead and run .\agpc-arm64.exe info -Json.

Preview scope

Linux installation verifies pinned runtime packages and Codex, preserves existing conffiles and records the result. Windows remains a diagnostic preview: its install command returns unavailable until the native Windows runtime bundle is supplied.

Run diagnostics without elevation. Package installation does not establish AGPC Ready: S-channel enrollment, application health, peer connectivity and RDP-over-Mote acceptance remain required. RDP host settings and credentials are managed by the native server. macOS remains specification-only.
