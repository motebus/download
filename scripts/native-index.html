Full installation

curl -fL https://motebus.github.io/download/agpc-all.sh -o agpc-all.sh
sudo bash ./agpc-all.sh

Requires native Ubuntu 24.04 or 26.04 amd64 with systemd, Bash and Python 3.10+. Run either script with --help for options. Installation shows a plan for confirmation.

Standard preserves existing applications. Full includes the renamed agpc-apps package and handles an installed legacy agent-apps through its transition package. Existing SQLite-based uChat installations need the separate offline migration before upgrading.

contextd runs inside AGPC. CoD Server (codd) remains in the cloud. Full Windows native integration and new S Channel / Agent identity integration remain separate work.

Windows

Download agpc.exe (x86-64): unsigned 0.1.0-host-access-preview.2, an outbound-access preview with FreeRDP 3.31.1 and native MCP. Run agpc.exe and approve Windows UAC when prompted. No Docker or WSL is required. First-time FreeRDP provisioning requires Internet access.

curl.exe -fL https://motebus.github.io/download/agpc.exe -o agpc.exe
.\agpc.exe

RDP uses its independent Mote channel. Windows Home can use the FreeRDP client; this does not add an RDP server to Windows Home. MCP binaries are packaged with deny-by-default policy. Local CDP is a preview.

This is not the complete AGPC host installer. The outbound profile does not include moted or provision inbound host access. Full uChat/contextd/Redis/CoD integration and remote CDP admission are incomplete. Remote SSH/RDP and MCP execution have not been accepted for this exact build. Native build and PowerShell 5.1/7 test suites passed; fixture tests do not establish remote readiness.

ARM64 remains the earlier manifest-dependent preview. Windows release notes, checksums and limitations.
