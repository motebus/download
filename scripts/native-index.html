Full installation

curl -fL https://motebus.github.io/download/agpc-all.sh -o agpc-all.sh
sudo bash ./agpc-all.sh

Requires native Ubuntu 24.04 or 26.04 amd64 with systemd, Bash and Python 3.10+. Run either script with --help for options. Installation shows a plan for confirmation.

Standard preserves existing applications. Full includes the renamed agpc-apps package and handles an installed legacy agent-apps through its transition package. Existing SQLite-based uChat installations need the separate offline migration before upgrading.

contextd runs inside AGPC. CoD Server (codd) remains in the cloud. Windows native support and new S Channel / Agent identity integration are separate future work.

Windows

Download agpc.exe (x86-64). The x86-64 download is the unsigned 0.1.0-host-access-preview.1 native host-access installer. Download and run agpc.exe, then approve Windows UAC. It bundles the Mote host-access components and handles OpenSSH setup. No Docker or WSL is required.

curl.exe -fL https://motebus.github.io/download/agpc.exe -o agpc.exe
.\agpc.exe

This locally built preview has authenticated SSH and operator-confirmed native RDP client evidence on one PC. It is not the full AGPC runtime; CDP, SFTP and clean-machine acceptance remain pending. The latest performance source change is not included. Full-runtime readiness may remain incomplete (exit code 3).

ARM64 remains the earlier manifest-dependent preview. Windows release notes and limitations.
